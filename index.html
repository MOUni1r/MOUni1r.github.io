My approach

The model is not the conclusion.

The strongest part of a data project is the reasoning between the raw dataset and the final recommendation.

01

Understand

Define the problem, target, data quality, and what a useful result would look like.

02

Investigate

Explore patterns, test assumptions, and use the right evidence for the question.

03

Model

Choose a suitable model, compare alternatives, and evaluate on data the model did not see.

04

Decide

Translate the result into an action, a priority, or a better question for the next analysis.
