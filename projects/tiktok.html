01 · Analysis & evidence

The model found a very strong classification signal, which also needs investigation.

The workflow moved from data-quality checks to text feature construction, model comparison, validation, and a final untouched test evaluation. The unusually high test performance is treated as a reason to inspect feature availability and possible label leakage before any real deployment.

Key findingEngagement and text-related variables showed strong separation between claims and opinions. That makes the model interesting, but it also makes feature timing and leakage checks essential.
02 · Model strategy

The method followed the question.

I used model comparison and evaluation to understand what the data could support, rather than treating the highest single score as the whole result.

CountVectorizerUnigram and bigram text features.
Random ForestSelected through validation model comparison.
Production checkRe-test using only features available when a video is first reported.
03 · Client value

What this work can help a client decide.

The project shows how classification can help prioritize moderation review, while the unusually high score makes feature timing and fresh-data validation more important than celebrating the metric.

ProblemModeration teams need a way to prioritize reported videos for human review.
What the analysis addsText and engagement signals can separate reported content and create a starting point for review prioritization.
Practical useUse the model as a review-prioritization aid, then validate it on fresh data with only information available at report time.
04 · Final conclusion

The result is useful when it changes the next decision.

The model is promising as a classification workflow, but the 99.95% result should trigger investigation rather than a production claim. The next useful step is a leakage-aware evaluation on fresh data collected at the moment a video is reported.

What we learnedEngagement and text-related variables showed strong separation between claims and opinions. That makes the model interesting, but it also makes feature timing and leakage checks essential.
What I would recommendThe model is promising as a classification workflow, but the 99.95% result should trigger investigation rather than a production claim. The next useful step is a leakage-aware evaluation on fresh data collected at the moment a video is reported.
What to watchThe 99.95% result is a portfolio result on an educational dataset, not a production generalization claim. Real deployment would need leakage checks, fresh data, calibration, fairness review, and monitoring.
05 · Recommendation & limits

What I would do next.

Recommended next steps

  • Use the model as a review-prioritization aid and validate it on fresh data with report-time features only.
  • Check leakage, calibrate probabilities, and monitor changes in content and engagement behavior.
