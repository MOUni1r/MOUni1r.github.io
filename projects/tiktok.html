01 · Analysis

The model found a very strong classification signal, which also needs investigation.

The workflow moved from data-quality checks to text feature construction, model comparison, validation, and a final untouched test evaluation. The unusually high test performance is treated as a reason to inspect feature availability and possible label leakage before any real deployment.

Key findingEngagement and text-related variables showed strong separation between claims and opinions. That makes the model interesting, but it also makes feature timing and leakage checks essential.

03 · Final conclusion

What a client could actually use from this work.

Client takeaway: The classification approach could help prioritize moderation review, but the unusually high test score makes feature timing and leakage checks essential before any real use.

Key findingEngagement and text-related variables showed very strong separation between claims and opinions, producing unusually high test performance.
Business impactIf validated on fresh, correctly timed data, a classifier could help moderation teams prioritize human review instead of treating every report equally.
Recommended actionUse the model as a review-prioritization aid, then validate it on fresh data with features available at report time.
LimitationsThe 99.95% result is a portfolio result on an educational dataset, not a production generalization claim. Leakage, calibration, fairness, and fresh-data checks are still required.
