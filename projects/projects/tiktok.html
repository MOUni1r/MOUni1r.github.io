What the model says

The headline result is useful only when paired with the trade-offs and statistical context around it.

Key finding

Reported videos showed a clear view-count difference.

265,664 vs 91,439

Mean video views were substantially higher for claim videos than opinion videos in the analyzed sample. A Welch two-sample test produced a t-statistic of 25.4994 with p = 2.60888 × 10⁻¹²⁰. This is an association in the dataset, not a causal claim.

Why this number is a flag, not just a win

99.95% test accuracy on a two-class problem is unusually high for real-world content moderation data. The most likely explanation is that this educational dataset bakes the claim/opinion label very close to the engagement variables (views, likes) themselves, rather than the model uncovering a genuinely subtle pattern. A production system would not have reliable engagement numbers at the moment a video is first reported, so before trusting a result like this I would re-test the model using only features available at report time, and validate on a fresh, real sample before it touches a real moderation queue.

05

What I'd recommend

A result is only useful once it is paired with how it should change what a moderation team actually does next.

01

Use the model to rank reported videos by likelihood of being a claim so moderators review the highest-risk queue first, not as an automatic takedown or automatic claim label.

02

Before any real deployment, check which engagement features (views, likes, shares) are actually available at the moment a video is first reported, not just later in its lifecycle. That decides whether this model can even run in production.

03

Treat the 99.95% test score as a signal to investigate, not a headline to lead with. Re-run the evaluation on a fresh, real-world sample before trusting it operationally.

04

Because the model leans heavily on engagement rather than transcript content, pair it with a lightweight text-based rule as a sanity check for videos that have little or no engagement history yet.

06

Limitations & next steps

A strong case study should make its boundaries visible.

01The dataset is simulated for educational use.
02Some engagement variables may only be available after interaction, so production prediction-time availability must be checked.
03The extremely high holdout performance should be validated on fresh real-world data before deployment.
