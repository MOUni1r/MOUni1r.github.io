01 · Analysis

Visual evidence before model interpretation.

The workflow combines data-quality checks, behavioral feature engineering, stratified train, validation, and test splits, model comparison, and threshold tuning using validation data only. The selected validation threshold increases recall while accepting more false positives; it is an example operating point, not a production recommendation.

Choose the method for the question.

Models are compared using metrics aligned with the problem, then evaluated on held-out data. The point is not a single score. It is understanding what the model can and cannot support.
