# TikTok Claims Classification

Portfolio case study focused on classifying TikTok videos as claims or opinions.

## Main work
- Data quality assessment
- Exploratory data analysis
- Welch's t-test
- Feature engineering
- CountVectorizer text features
- Random Forest and XGBoost
- Validation-based model selection
- Held-out test evaluation
- Feature importance
- Limitations and deployment considerations

## Final test result
Random Forest:
- Accuracy: 99.95%
- Precision: 100.00%
- Recall: 99.90%
- F1: 99.95%

The dataset is simulated for educational purposes. Results should not be presented as evidence about real TikTok systems.
