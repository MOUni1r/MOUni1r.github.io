01 · Analysis

Visual evidence before model interpretation.

This independent portfolio case study combines data-quality cleaning, time and trip-level EDA, statistical testing, leakage-aware feature engineering, cross-validated model selection, held-out test evaluation, and error analysis. The dataset is educational and the payment comparison is observational.

Key finding

Payment method was associated with average fare.

02 · Model strategy

Choose the method for the question.

Models are compared using metrics aligned with the problem, then evaluated on held-out data. The point is not a single score. It is understanding what the model can and cannot support.

Interpretation

Portfolio framing

This is a portfolio case study built from an educational dataset. Results are presented as analytical evidence and model behavior, not as proof of causal relationships or production performance.

04 · Practical next steps

What I would investigate next.

  • Treat the card-vs-cash fare gap as an operational question, not a causal pricing rule.
  • Flag high-fare predictions for manual review because errors grow in that segment.
  • Keep route-level aggregate features tied to training data when moving toward production.
