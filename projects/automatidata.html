01 · Analysis & evidence

Payment method was associated with average fare, while fare prediction remained difficult.

The workflow combined data-quality checks, trip-level EDA, statistical testing, leakage-aware feature engineering, cross-validated model selection, held-out evaluation, and error analysis. The payment comparison is observational, not a causal pricing rule.

Key findingThe card and cash groups showed a measurable average fare difference, while fare prediction remained difficult enough that errors should be treated as an operational signal rather than an exact estimate.

03 · Client value

What this work can help a client decide.

The useful outcome is not a perfect fare predictor. It is a clearer view of fare behavior, payment-method differences, and where prediction errors become important.

ProblemTaxi data contains useful patterns, but raw averages can hide differences between payment methods and trip conditions.
What the analysis addsStatistical testing and model evaluation separate measurable associations from predictions that are too noisy to use as exact estimates.
Practical useUse the analysis to investigate fare behavior and flag unusual or high-error cases for further review.
04 · Final conclusion

The result is useful when it changes the next decision.

The analysis supports using the dataset for pattern detection and operational investigation, not as a precise fare engine. The payment difference is an association that can guide further analysis, while the modest R² shows why prediction errors must remain visible.
